# Scoring rubric

Three axes, scored 0–5 each, independently. Never blend into one number for
display — publish all three.

Weighting when ties break: Quality > Value > Desirability.

## Value — merit relative to price
0 no relation to worth | 3 fair for the class | 5 clearly underpriced for merit
Evidence required: realised comparables, last-seen ask, class median.
Sub-criteria: class median spread · realised-vs-estimate history · liquidity
(time-to-sale) · depreciation curve · total cost to own.

## Quality — the thing itself
0 compromised | 3 sound | 5 best-in-class execution
Evidence required: condition report, provenance chain, materials, maker record.
Sub-criteria: condition grade · originality/completeness · materials · maker
reputation · documentation · restoration or intervention history.

## Desirability — measured demand
0 no demand | 3 steady | 5 contested
Evidence required: over-estimate multiples, secondary premium, waitlist, search
volume, collector concentration.
Sub-criteria: over-estimate rate · premium over retail · waitlist length ·
search trend · notable provenance · scarcity.

## Per-department additions
- Time: movement originality, service history, box/papers, reference rarity
- The Sea: naval architecture, refit history, crew-keeping, flag/registration
- The Road: matching numbers, originality, event eligibility, documentation
- Estates: land, aspect, architectural significance, planning constraints
- The Table: fill level, bottle/case condition, release size, bond status
- The Field: bore, proof, barrel wall thickness, stock dimensions, cast
- Style: size availability, hardware completeness, authentication status
- Art: exhibition history, literature, edition size, condition report

## Inclusion floor
Quality < 3 disqualifies regardless of Value or Desirability.
Desirability alone never carries an item.
